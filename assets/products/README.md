# Product Images

Upload your product images in this folder and update image paths in `script.js` (`PRODUCT_CATALOG`).

Recommended:
- Format: `.jpg`, `.png`, or `.webp`
- Size: around `800x800`
- Keep file names simple, e.g. `kundan-necklace.jpg`

Example:
```js
{ id: "necklace-3", name: "New Necklace", price: 1299, image: "assets/products/kundan-necklace.jpg" }
```
